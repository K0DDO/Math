# Квадратичные формы, Сильвестр, кривые 2 порядка

## Введение / определения с нуля

**Линейная форма** — $l(x)=\sum a_i x_i$.

**Билинейная** — линейна по каждому аргументу. В базисе $B(x,y)=x^TAy$.

**Квадратичная форма** $Q(x)=B(x,x)=x^TAx$, матрица $A$ симметрическая: диагональ — коэффициенты при $x_i^2$, вне диагонали — половины коэффициентов при $x_ix_j$.

Диагонализация:

- **собственные числа:** ортогональная замена (для симметричной $A$) приводит $Q$ к $\lambda_1 y_1^2+\cdots+\lambda_n y_n^2$;
- **Лагранж:** последовательное выделение полных квадратов;
- **Якоби:** через угловые миноры, $Q=\sum\frac{\Delta_k}{\Delta_{k-1}}z_k^2$ при ненулевых $\Delta_k$.

**Знакоопределённость:**

- положительно определённая: $Q(x)>0$ при $x\neq 0$;
- отрицательно определённая: $Q(x)<0$ при $x\neq 0$;
- полуопределённые — неравенства нестрогие;
- знакопеременная — принимает оба знака.

**Критерий Сильвестра.** $Q>0$ $\Leftrightarrow$ все угловые миноры $\Delta_k>0$. $Q<0$ $\Leftrightarrow$ знаки $\Delta_k$ чередуются, начиная с $\Delta_1<0$.

Эквивалентно: все $\lambda_i>0$ (соотв. все $<0$).

Кривая / поверхность 2 порядка: квадратичная часть + линейная. Приводишь квадратичную форму к канону ортогональным преобразованием, потом сдвигаешь координаты (выделяешь полный квадрат / сдвиг).

**Блочные матрицы:** сложение и умножение по блокам, если размеры согласованы. Определитель блочно-треугольной $\det\begin{pmatrix}A&B\\0&C\end{pmatrix}=\det A\det C$.

## Как решать (пошагово)

Сильвестр для $n=2,3$: выпиши $A$, посчитай $\Delta_1=a_{11}$, $\Delta_2=\det\begin{pmatrix}a_{11}&a_{12}\\a_{21}&a_{22}\end{pmatrix}$, $\Delta_3=\det A$. Сравни с критерием.

Лагранж: если есть $x^2$, собери все члены с $x$: $a(x+\cdots)^2+\text{остаток без }x$. Повтори.

Канон кривой $ax^2+2bxy+cy^2+dx+ey+f=0$:

1. Поверни, чтобы убить $xy$ (это диагонализация квадратичной части).
2. Сдвинь, чтобы убить линейные члены.
3. Подели, получи $\frac{X^2}{A}+\frac{Y^2}{B}=1$ и т. д. Назови: эллипс, гипербола, парабола, вырожденная.

## Примеры с разбором

### Пример 1. Сильвестр

$Q=x^2+4xy+y^2$, $A=\begin{pmatrix}1&2\\2&1\end{pmatrix}$.

$\Delta_1=1>0$, $\Delta_2=-3<0$ — знакопеременная.

Канон по собственным: $\lambda=3,-1$, $Q=3u^2-v^2$.

### Пример 2. Лагранж

$Q=x^2+2xy+2y^2=(x+y)^2+y^2$. Уже сумма квадратов, положительно определённая. Миноры: $\Delta_1=1$, $\Delta_2=2-1=1>0$, сходится.

### Пример 3. Кривая

$x^2+4xy+4y^2+2x=0$. Квадратичная часть $(x+2y)^2$. Замена $u=x+2y$, потом сдвиг по $u$. Получится парабола (один квадрат и линейный член).

## Типичные ошибки / вопросы на экзамен

- в матрицу формы ставить коэффициент при $xy$ целиком, а не половину;
- путать Сильвестра с критерием для отрицательной определённости;
- ортогональную замену для кривой делать «не ортогонально» — оси перекашиваются, канон геометрически врёт;
- забыть линейные члены после диагонализации квадратичной части.
