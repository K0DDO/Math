# Вопрос 30. Неоднородные системы. Специальная правая часть. Неопределённые коэффициенты

## Зачем это в жизни и на экзамене

Если внешняя сила $G(t)$ — константа, многочлен, экспонента или синус/косинус (векторные коэффициенты), частное решение системы угадывают **по виду**, как в вопросе 24. Так моделируют постоянный ветер / постоянный приток, гармонический привод связанных осцилляторов и резонанс, когда частота силы совпадает с собственной. На экзамене ждут правильный анзац и резонансный множитель $t^{s}$.

На экзамене обычно спрашивают:

- какие $G$ считаются специальными для систем;
- выбор вида $X_{\mathrm{ч}}$;
- резонанс: если $e^{\alpha t}$ или $e^{\alpha t}\cos/\sin$ уже в однородном решении;
- отличие от вариации (вопрос 29).

## Интуиция на пальцах

Постоянный ветер дует на связанную конструкцию — ищем **постоянный** (или линейный по $t$, если «ноль в спектре») сдвиг равновесия. Синусоидальный мотор крутит с частотой $\Omega$ — ищем отклик той же частоты. Если $\Omega$ совпала с собственной частотой без демпфирования — амплитуда растёт (множитель $t$): резонанс связанной системы.

Коротко: таблица «какая сила → какой векторный отклик», плюс штраф $t^{s}$ при резонансе.

## Все понятия с нуля

### Специальная правая часть системы

**Интуиция.** Векторная сила из «закрытого списка».

**Определение.** Вектор-функция вида

$$G(t)=e^{\alpha t}\bigl(P(t)\cos\beta t+Q(t)\sin\beta t\bigr),$$

где $P,Q$ — векторные многочлены (столбцы многочленов). Частые случаи: постоянный вектор, $e^{\alpha t}V_0$, $A_0\cos\beta t+B_0\sin\beta t$. ([урок](https://mathprofi.ru/kak_reshit_sistemu_differencialnyh_uravnenii.html))

**Как узнать.** Если компоненты $G$ — $\tan t$, $1/t$ и т.п. — не специальная → вариация (вопрос 29).

### Метод неопределённых коэффициентов для систем

**Интуиция.** Векторный шаблон с неизвестными столбцами-коэффициентами.

**Определение.** Подбор $X_{\mathrm{ч}}$ того же класса с неизвестными векторными коэффициентами; подстановка в $X'=AX+G$ даёт алгебраические уравнения на эти коэффициенты. ([урок](https://mathprofi.ru/kak_reshit_sistemu_differencialnyh_uravnenii.html))

**Как применить.** Выбрать анзац → производная → приравнять коэффициенты при одинаковых функциях.

### Резонанс для систем

**Интуиция.** Частота / показатель силы совпал со спектром $A$.

**Определение.** Если функции вида $e^{\alpha t}$, $e^{\alpha t}\cos\beta t$, $e^{\alpha t}\sin\beta t$ уже входят в однородное решение (то есть $\alpha+i\beta$ — собственное значение $A$), шаблон $X_{\mathrm{ч}}$ умножают на подходящую степень $t$. Практическое правило: умножать на $t^{s}$, где $s$ — минимальная степень, при которой анзац перестаёт быть решением однородной (часто $s=1$ для простого собственного значения). ([урок](https://mathprofi.ru/kak_reshit_sistemu_differencialnyh_uravnenii.html))

**Как проверить.** Сравни $\alpha+i\beta$ со спектром $A$ из вопросов 26–28.

### Суперпозиция

**Интуиция.** Сумма сил → сумма частных решений.

**Определение.** Если $G=G_1+G_2$, ищем $X_{\mathrm{ч}}=X_{\mathrm{ч},1}+X_{\mathrm{ч},2}$. ([урок](https://mathprofi.ru/kak_reshit_sistemu_differencialnyh_uravnenii.html))

## Теория подробно

Сначала полностью решаем $X'=AX$ и знаем, какие моды уже «заняты».

### Постоянная правая часть $G(t)\equiv G_0$

- Если $0$ не собственное значение $A$ (матрица обратима): ищем постоянное $X_{\mathrm{ч}}=K$, откуда $0=AK+G_0$, то есть $K=-A^{-1}G_0$.
- Если $0$ — собственное значение: постоянное равновесие может не существовать; ищем $X_{\mathrm{ч}}=Kt+M$ (или выше при большей жордановой структуре).

Это значит: постоянная нагрузка сдвигает равновесие, а при «нулевой моде» накапливается линейный дрейф.

### Экспонента $G=e^{\alpha t}G_0$

Ищем $X_{\mathrm{ч}}=e^{\alpha t}K$, если $\alpha$ не собственное:

$$(\alpha E-A)K=G_0.$$

Если $\alpha$ — собственное, умножаем на $t$ (или берём $e^{\alpha t}(tK+M)$).

### Гармоника $G=A_0\cos\beta t+B_0\sin\beta t$

Ищем

$$X_{\mathrm{ч}}=U\cos\beta t+W\sin\beta t$$

(векторы $U,W$ неизвестны), если $\pm i\beta$ не собственные. Подстановка даёт линейную систему на $U,W$. При резонансе ($\pm i\beta$ — собственные) —

$$X_{\mathrm{ч}}=t(U\cos\beta t+W\sin\beta t)$$

(иногда плюс ещё $\cos/\sin$ без $t$; на практике часто достаточно $t$-шаблона с полным набором коэффициентов / аккуратного расширения).

### Связь со скалярным вопросом 24

Companion-система скалярного уравнения воспроизводит те же правила: специальная $g$ → специальный вектор $G$, резонанс — те же $t^{s}$.

## Примеры из практики (мир)

### 1. Постоянный ветер / постоянная сила

На связанную конструкцию: новое статическое смещение $K=-A^{-1}G_0$ (если устойчивая матрица без нулевого собственного значения). Мост под постоянной нагрузкой ветра в линейной модели.

### 2. Постоянный приток в систему баков

Если есть сток — новое равновесие; если закон сохранения (нулевая мода) — уровень растёт линейно со временем. Это значит: «дыра в спектре на нуле» = накопление.

### 3. Резонансный привод связанных осцилляторов

Сила $\cos\Omega t$ на одной массе при $\Omega$, равной собственной частоте без трения → частное с множителем $t$ — раскачка моды. Опасность для конструкций и машин.

### 4. AC-питание двух связанных контуров

Установившийся режим той же частоты (без $t$), если есть сопротивление (действительная часть собственных чисел сдвигает $\alpha\neq 0$ и уводит от чистого резонанса).

## Алгоритм «как решать на экзамене»

1. Реши однородную, выпиши спектр $A$ и вид $X_{\mathrm{о.о.}}$.
2. Определи тип $G$ (константа / экспонента / синус–косинус / сумма).
3. Выбери анзац $X_{\mathrm{ч}}$; если соответствующее $\alpha+i\beta$ — собственное, умножь на $t^{s}$.
4. Подставь в $X'=AX+G$, приравнивая коэффициенты при одинаковых функциях, найди неизвестные векторы.
5. Запиши общее $X=X_{\mathrm{о.о.}}+X_{\mathrm{ч}}$.

Если застрял с видом — вариация (вопрос 29) всегда спасает.

## Разобранный пример

Система

$$X'=\begin{pmatrix} 0 & 1 \\\\ -1 & 0 \end{pmatrix} X+\begin{pmatrix} 0 \\\\ 1 \end{pmatrix}.$$

**Однородная.** Собственные $\pm i$ (вращение), общее однородное — комбинации $\cos t,\sin t$ в компонентах (центр).

**Правая часть** — постоянный вектор $G_0=\begin{pmatrix} 0 \\\\ 1 \end{pmatrix}$. Число $0$ **не** собственное значение. Ищем постоянное $X_{\mathrm{ч}}=K=\begin{pmatrix} k_1 \\\\ k_2 \end{pmatrix}$:

$$0=AK+G_0 \Rightarrow A K=-G_0.$$

То есть

$$\begin{pmatrix} 0 & 1 \\\\ -1 & 0 \end{pmatrix}\begin{pmatrix} k_1 \\\\ k_2 \end{pmatrix}=\begin{pmatrix} 0 \\\\ -1 \end{pmatrix}.$$

Отсюда $k_2=0$, $-k_1=-1$, то есть $k_1=1$. Значит

$$X_{\mathrm{ч}}=\begin{pmatrix} 1 \\\\ 0 \end{pmatrix}.$$

Общее решение: колебания вокруг нового центра $\begin{pmatrix} 1 \\\\ 0 \end{pmatrix}$. Это значит: постоянная сила сместила равновесие, не разрушив круговую динамику отклонений.

**Резонансный набросок.** Если бы $G=\begin{pmatrix} \cos t \\\\ 0 \end{pmatrix}$ при той же $A$ (частота $1$ совпадает с собственной), искали бы

$$X_{\mathrm{ч}}=t(U\cos t+W\sin t)$$

и находили $U,W$ подстановкой — амплитуда линейно растёт.

## Практика

1. Для $X'=AX+G_0$ с обратимой $A$ выпишите $X_{\mathrm{ч}}$.
2. Почему при $G=\mathrm{const}$ и $\lambda=0$ в спектре $A$ нельзя ограничиться постоянным $K$?
3. Подберите вид $X_{\mathrm{ч}}$ для $G=e^{2t}\begin{pmatrix} 1 \\\\ 0 \end{pmatrix}$, если $2$ не собственное.
4. Подберите вид при том же $G$, если $2$ — простое собственное значение.
5. Чем метод этого вопроса быстрее вариации и когда он бесполезен?

**Ответы:**

1. $X_{\mathrm{ч}}=-A^{-1}G_0$.
2. Уравнение $AK=-G_0$ может не иметь решения; нужен рост по $t$.
3. $e^{2t}K$.
4. $e^{2t}(tK+M)$ (или $t e^{2t}K$ в простейшем анзаце с проверкой).
5. Быстрее на специальных $G$; бесполезен для «уродливых» $G$ — тогда вопрос 29.

## Что сказать устно за 1–2 минуты

Для специальной векторной правой части частное решение системы ищут того же вида с неопределёнными векторными коэффициентами. Постоянная сила даёт новое равновесие $K=-A^{-1}G_0$, если $0$ не в спектре. Гармонический привод — отклик той же частоты; при совпадении с собственной — множитель $t$ и резонанс. Иначе всегда работает вариация постоянных.
