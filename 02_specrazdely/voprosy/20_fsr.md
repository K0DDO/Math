# Вопрос 20. Фундаментальная система решений. Структура общего решения однородного уравнения

## Что спрашивают на экзамене

- Определение ФСР (фундаментальной системы решений).
- Теорема существования ФСР.
- Структура общего решения ЛОДУ: $y=\sum C_i y_i$.
- Связь с размерностью пространства решений и с вронскианом.

## Все понятия с нуля

**Частное решение** ЛОДУ — одна функция, для которой $L[y]=0$.

**Фундаментальная система решений (ФСР)** уравнения порядка $n$ — набор из **ровно $n$ линейно независимых** частных решений $y_1,\ldots,y_n$.

По-другому: ФСР — **базис** пространства решений.

**Общее решение однородного** (общее однородное, $y_{\mathrm{о.о.}}$) — формула, содержащая $n$ произвольных постоянных и охватывающая **все** решения.

**Вронскиан ФСР** обязательно $W\neq 0$ (см. вопрос 19) — это и есть проверка, что набор действительно фундаментальный.

## Теория подробно

Рассмотрим
$$L[y]=y^{(n)}+p_{n-1}(x)y^{(n-1)}+\cdots+p_0(x)y=0$$
с непрерывными $p_i$ на интервале $I$.

**Теорема существования ФСР.** Существует набор из $n$ линейно независимых решений. (Конструктивно: взять решения задач Коши с начальными данными — столбцы единичной матрицы в точке $x_0$; их вронскиан в $x_0$ равен $1\neq 0$.)

**Структура общего решения:**
$$y_{\mathrm{о.о.}}(x)=C_1 y_1(x)+C_2 y_2(x)+\cdots+C_n y_n(x),$$
где $\{y_1,\ldots,y_n\}$ — любая ФСР, $C_i$ — произвольные постоянные.

**Смысл:**
- любая такая комбинация — решение (линейность $L$);
- любое решение получается при подходящем выборе $C_i$ (базисность ФСР);
- число произвольных постоянных равно порядку уравнения.

Для $n=2$: если $W(y_1,y_2)\neq 0$, то
$$y=C_1 y_1+C_2 y_2.$$

Найти ФСР = полностью решить однородное уравнение.

## Как решать / алгоритм

1. Найти $n$ частных решений (для постоянных коэффициентов — через характеристическое уравнение, вопрос 23).
2. Проверить линейную независимость: $W\neq 0$.
3. Записать $y=\sum C_i y_i$.
4. При задаче Коши: подставить начальные условия, решить систему для $C_i$.

## Разобранный пример

Уравнение $y''-y=0$. Ищем решения вида $e^{kx}$: $k^2-1=0$, $k=\pm 1$.

Частные решения: $y_1=e^{x}$, $y_2=e^{-x}$.
$$W=\begin{vmatrix} e^{x} & e^{-x} \\\\ e^{x} & -e^{-x} \end{vmatrix}=-1-1=-2\neq 0.$$
Значит, это ФСР. Общее решение:
$$y=C_1 e^{x}+C_2 e^{-x}.$$
Эквивалентная ФСР: $\cosh x$, $\sinh x$ (линейные комбинации $e^{\pm x}$).

Задача Коши $y(0)=1$, $y'(0)=0$:
$$\begin{cases} C_1+C_2=1, \\\\ C_1-C_2=0 \end{cases} \Rightarrow C_1=C_2=\tfrac12 \Rightarrow y=\cosh x.$$

## Практика

1. Является ли $\{e^{2x},\,2e^{2x}\}$ ФСР для $y'-2y=0$ (порядок 1)? Почему?
2. Для $y'''-y''=0$ предложите три кандидата в ФСР и проверьте $W$.
3. Показать, что если $\{y_1,y_2\}$ — ФСР, то $\{y_1+y_2,\,y_1-y_2\}$ — тоже ФСР.
4. Сколько произвольных постоянных в общем решении уравнения 4-го порядка?

**Ответы:** 1) нет, зависимы; 2) например $1$, $x$, $e^{x}$ (корни $0,0,1$); 3) новый вронскиан $= -2W\neq 0$; 4) четыре.

## Что сказать устно за 1 минуту

ФСР — это $n$ линейно независимых частных решений однородного уравнения порядка $n$, то есть базис пространства решений. Общее решение — произвольная линейная комбинация функций из ФСР: $y=C_1 y_1+\cdots+C_n y_n$. Независимость проверяют вронскианом: $W\neq 0$. Найти ФСР значит полностью решить однородное уравнение.
