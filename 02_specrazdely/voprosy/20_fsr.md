# Вопрос 20. Фундаментальная система решений. Структура общего решения однородного уравнения

## Зачем это в жизни и на экзамене

ФСР — это **базис** пространства свободных движений линейной системы: минимальный набор независимых мод, из которых складывается любое свободное колебание. Ударил груз на пружине — получил комбинацию $\cos$ и $\sin$; отпустил струну — сумму гармоник. На экзамене ФСР — центральное понятие: без него нет общего решения однородного и нет перехода к неоднородному (вариация, специальная правая часть).

На экзамене обычно спрашивают:

- определение **ФСР**;
- теорему существования ФСР;
- структуру $y=\sum C_i y_i$;
- связь с размерностью пространства решений и с вронскианом.

## Интуиция на пальцах

В $\mathbb{R}^{n}$ любой вектор — комбинация базисных. Пространство решений ЛОДУ порядка $n$ тоже «$n$-мерно»: любая свободная эволюция — комбинация $n$ независимых частных решений. ФСР — и есть этот базис. Проверка базиса — вронскиан $\neq 0$ (вопрос 19). Константы $C_i$ подбираются под начальные положение и скорость (и высшие производные).

## Все понятия с нуля

### Частное решение ЛОДУ

**Интуиция.** Одна конкретная свободная мода / траектория.

**Определение.** Функция, для которой $L[y]=0$. ([урок](https://mathprofi.ru/differencialnye_uravnenija_vtorogo_poryadka.html))

### Фундаментальная система решений (ФСР)

**Интуиция.** Полный набор независимых мод — базис.

**Определение.** Для уравнения порядка $n$ ФСР — набор из **ровно $n$ линейно независимых** частных решений $y_1,\ldots,y_n$. По-другому: ФСР — **базис** пространства решений. ([урок](https://mathprofi.ru/differencialnye_uravnenija_vtorogo_poryadka.html))

**Как проверить.** Ровно $n$ штук + $W\neq 0$.

### Общее решение однородного

**Интуиция.** Все возможные свободные движения сразу.

**Определение.** Формула с $n$ произвольными постоянными, охватывающая **все** решения $L[y]=0$; обозначение часто $y_{\mathrm{о.о.}}$. ([урок](https://mathprofi.ru/differencialnye_uravnenija_vtorogo_poryadka.html))

### Вронскиан ФСР

**Интуиция.** Сертификат независимости мод.

**Определение.** Для ФСР обязательно $W(y_1,\ldots,y_n)\neq 0$ (вопрос 19). ([урок](https://mathprofi.ru/differencialnye_uravnenija_vtorogo_poryadka.html))

## Теория подробно

Рассмотрим

$$L[y]=y^{(n)}+p_{n-1}(x)y^{(n-1)}+\cdots+p_0(x)y=0$$

с непрерывными $p_i$ на интервале $I$.

### Теорема существования ФСР

Существует набор из $n$ линейно независимых решений. Конструктивно: взять решения задач Коши, чьи начальные данные в точке $x_0$ образуют столбцы единичной матрицы; их вронскиан в $x_0$ равен $1\neq 0$. ([урок](https://mathprofi.ru/linejnye_diffury_vysshih_porjadkov.html))

Это значит: пространство решений не «дырявое» — базис всегда есть (при непрерывных коэффициентах).

### Структура общего решения

$$y_{\mathrm{о.о.}}(x)=C_1 y_1(x)+C_2 y_2(x)+\cdots+C_n y_n(x),$$

где $\{y_1,\ldots,y_n\}$ — любая ФСР, $C_i$ — произвольные постоянные. ([урок](https://mathprofi.ru/differencialnye_uravnenija_vtorogo_poryadka.html))

**Смысл:**
- любая такая комбинация — решение (линейность $L$, вопрос 18);
- любое решение получается при подходящем выборе $C_i$ (базисность ФСР);
- число произвольных постоянных равно порядку уравнения.

Для $n=2$: если $W(y_1,y_2)\neq 0$, то $y=C_1 y_1+C_2 y_2$.

Найти ФСР = полностью решить однородное уравнение.

### Замена ФСР

Если $\{y_i\}$ — ФСР и матрица перехода $A$ невырождена ($\det A\neq 0$), то новые функции

$$z_j=\sum_{i=1}^{n} y_i a_{ij}$$

тоже ФСР. Это значит: базис можно «крутить»; общее решение описывает то же пространство.

### Связь с задачей Коши

Подстановка $y=\sum C_i y_i$ в условия $y(x_0),\ldots,y^{(n-1)}(x_0)$ даёт линейную систему на $C_i$ с определителем $W(x_0)\neq 0$ — решение для констант всегда единственно.

## Примеры из практики (мир)

### 1. Свободные колебания: моды складываются

Одномерный осциллятор $y''+\omega^{2} y=0$: ФСР $\{\cos\omega t,\,\sin\omega t\}$. Любое свободное движение:

$$y(t)=C_1\cos\omega t+C_2\sin\omega t=A\cos(\omega t-\varphi).$$

Это значит: две моды комбинируются в одну гармонику с амплитудой и фазой.

### 2. Затухающие колебания

Уравнение $y''+2\gamma y'+\omega_0^{2} y=0$ при малом трении: ФСР вида $e^{-\gamma t}\cos\omega t$, $e^{-\gamma t}\sin\omega t$. Общее решение — их комбинация: все свободные затухающие режимы.

### 3. Струна / балка (идея)

После разделения переменных по каждой моде времени остаётся линейное ОДУ; общее поперечное движение — суперпозиция мод. Конечномерная проекция — снова «ФСР × коэффициенты».

### 4. Электрический контур без источника

Свободный ток в RLC — комбинация двух независимых решений характеристического уравнения; константы из $i(0)$, $u_C(0)$.

## Алгоритм «как решать на экзамене»

1. Найти $n$ частных решений (для постоянных коэффициентов — характеристическое уравнение, вопрос 23).
2. Проверить линейную независимость: $W\neq 0$.
3. Записать $y=\sum C_i y_i$.
4. При задаче Коши: подставить начальные условия, решить систему для $C_i$.
5. Сказать: ФСР — базис, размерность пространства решений равна $n$.

## Разобранный пример

Уравнение $y''-y=0$. Ищем $e^{kx}$: $k^{2}-1=0$, $k=\pm 1$.

Частные решения: $y_1=e^{x}$, $y_2=e^{-x}$.

$$W=\begin{vmatrix} e^{x} & e^{-x} \\\\ e^{x} & -e^{-x} \end{vmatrix}=-1-1=-2\neq 0.$$

Значит, это ФСР. Общее решение:

$$y=C_1 e^{x}+C_2 e^{-x}.$$

Эквивалентная ФСР: $\cosh x$, $\sinh x$ (невырожденная замена от $e^{\pm x}$).

Задача Коши $y(0)=1$, $y'(0)=0$:

$$\begin{cases} C_1+C_2=1, \\\\ C_1-C_2=0 \end{cases}$$

⇒ $C_1=C_2=\dfrac{1}{2}$ ⇒ $y=\cosh x$.

**Осциллятор.** $y''+y=0$, ФСР $\cos x$, $\sin x$, $W=1$. Коши $y(0)=0$, $y'(0)=1$ ⇒ $y=\sin x$.

## Практика

1. Является ли $\{e^{2x},\,2e^{2x}\}$ ФСР для $y'-2y=0$ (порядок 1)? Почему?
2. Для $y'''-y''=0$ предложите три кандидата в ФСР и проверьте идею $W\neq 0$.
3. Показать, что если $\{y_1,y_2\}$ — ФСР, то $\{y_1+y_2,\,y_1-y_2\}$ — тоже ФСР.
4. Сколько произвольных постоянных в общем решении уравнения 4-го порядка?
5. Для $y''+4y=0$ выписать ФСР и общее решение; найти решение с $y(0)=1$, $y'(0)=0$.

**Ответы:**
1. Нет, зависимы ($W=0$); для порядка 1 нужна **одна** независимая функция, например $e^{2x}$.
2. Например $1$, $x$, $e^{x}$ (характеристические корни $0,0,1$).
3. Новый вронскиан $=-2W\neq 0$ при $W\neq 0$.
4. Четыре.
5. ФСР $\cos 2x$, $\sin 2x$; общее $C_1\cos 2x+C_2\sin 2x$; Коши → $y=\cos 2x$.

## Что сказать устно за 1–2 минуты

ФСР — это $n$ линейно независимых частных решений однородного уравнения порядка $n$, то есть базис пространства решений. Общее решение — произвольная линейная комбинация функций из ФСР: $y=C_1 y_1+\cdots+C_n y_n$. Независимость проверяют вронскианом: $W\neq 0$. Найти ФСР значит полностью решить однородное уравнение. В приложениях свободные колебания — всегда комбинация независимых мод; константы фиксируются начальными условиями.
