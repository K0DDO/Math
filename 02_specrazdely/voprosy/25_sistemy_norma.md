# Вопрос 25. Нормальная система ДУ. Задача Коши. Существование и единственность. Сведение системы и уравнения высшего порядка

## Что спрашивают на экзамене

- Определение нормальной системы 1-го порядка.
- Что такое решение системы; геометрический смысл.
- Задача Коши; теорема существования и единственности.
- Как систему свести к одному уравнению высшего порядка и наоборот.

## Все понятия с нуля

**Система дифференциальных уравнений** — несколько ДУ на несколько неизвестных функций одной независимой переменной (часто $t$). ([урок](https://mathprofi.ru/sistemy_differencialnyh_uravnenij.html))

**Нормальная форма** — система, разрешённая относительно первых производных:

$$\begin{cases} x_1'=f_1(t,x_1,\ldots,x_n), \\\\ \vdots \\\\ x_n'=f_n(t,x_1,\ldots,x_n), \end{cases} \qquad {}'= \dfrac{d}{dt}.$$

Для двух неизвестных обычно пишут $x',y'$. ([урок](https://mathprofi.ru/sistemy_differencialnyh_uravnenij.html))

**Решение** — набор функций $x_1(t),\ldots,x_n(t)$ (вектор-функция $\mathbf{x}(t)$), который при подстановке обращает каждое уравнение в тождество. ([урок](https://mathprofi.ru/sistemy_differencialnyh_uravnenij.html))

**Фазовое пространство** — пространство переменных $\,(x_1,\ldots,x_n)$; решение — кривая (траектория). При $n=2$ — кривая на плоскости. ([урок](https://mathprofi.ru/sistemy_differencialnyh_uravnenij.html))

**Задача Коши:** найти решение с начальным условием

$$\mathbf{x}(t_0)=\mathbf{x}_0 \quad\bigl(x_i(t_0)=x_{i0}\bigr).$$

([урок](https://mathprofi.ru/sistemy_differencialnyh_uravnenij.html))

## Теория подробно

### Теорема существования и единственности

Если функции $f_i$ и частные производные $\partial f_i/\partial x_j$ непрерывны в области, содержащей точку $\,(t_0,\mathbf{x}_0)$, то в некоторой окрестности $t_0$ существует **единственное** решение задачи Коши. ([урок](https://mathprofi.ru/sistemy_differencialnyh_uravnenij.html))

Смысл: через заданную точку фазового пространства (в момент $t_0$) проходит ровно одна интегральная кривая системы.

### Система → одно уравнение порядка $n$

Идея метода исключения: дифференцируем одно из уравнений и исключаем «лишние» неизвестные.

Пример $n=2$:

$$\begin{cases} x'=f(t,x,y), \\\\ y'=g(t,x,y). \end{cases}$$

Из первого (если возможно) выражаем $y=\ldots$, дифференцируем, подставляем во второе — получаем уравнение 2-го порядка на $x(t)$. Потом возвращаем $y$.

### Одно уравнение порядка $n$ → нормальная система

Для $y^{(n)}=f(t,y,y',\ldots,y^{(n-1)})$ полагают

$$x_1=y,\quad x_2=y',\quad \ldots,\quad x_n=y^{(n-1)}.$$

Тогда

$$\begin{cases} x_1'=x_2, \\\\ x_2'=x_3, \\\\ \vdots \\\\ x_n'=f(t,x_1,\ldots,x_n). \end{cases}$$

Поэтому теория систем покрывает уравнения высших порядков. ([урок](https://mathprofi.ru/kak_reshit_sistemu_differencialnyh_uravnenii.html))

## Как решать / алгоритм (исключение для $n=2$)

1. Из одного уравнения выразить одну неизвестную (ту, что удобнее).
2. Продифференцировать это выражение.
3. Подставить во второе уравнение → ДУ 2-го порядка на одну функцию.
4. Решить его (часто — линейное с постоянными коэффициентами).
5. Вернуться ко второму выражению и найти вторую функцию.
6. При Коши — найти константы из начальных условий.

## Разобранный пример

Система:

$$\begin{cases} x'=y, \\\\ y'=-x, \end{cases} \qquad x(0)=1,\ y(0)=0.$$

Из первого $y=x'$. Дифференцируем: $y'=x''$. Во второе: $x''=-x$, то есть $x''+x=0$.

$$x=C_1\cos t+C_2\sin t,\qquad y=x'=-C_1\sin t+C_2\cos t.$$

Условия: $x(0)=C_1=1$, $y(0)=C_2=0$.

$$x=\cos t,\qquad y=-\sin t.$$

Обратный ход: уравнение $u''+u=0$ → система $x_1=u$, $x_2=u'$, $x_1'=x_2$, $x_2'=-x_1$.

## Практика

1. Свести $y'''=t+y'+y$ к нормальной системе.
2. Для 

$$\begin{cases}x'=2x+y \\\\ y'=3x+4y\end{cases}$$

 наметить исключение.
3. Сформулировать задачу Коши для системы трёх уравнений.
4. Почему непрерывности одних $f_i$ мало — нужны ещё $\partial f_i/\partial x_j$?

**Ответы:** 1) $x_1=y$, $x_2=y'$, $x_3=y''$, $x_3'=t+x_2+x_1$; 2) выразить $y=x'-2x$, дифференцировать, подставить; 3) $\mathbf{x}(t_0)=\mathbf{x}_0\in\mathbb R^{3}$; 4) для единственности нужна липшицевость по $\mathbf{x}$, её дают непрерывные частные производные.

## Что сказать устно за 1 минуту

Нормальная система — это $x_i'=f_i(t,\mathbf{x})$. Решение — вектор-функция; Коши задаёт точку в момент $t_0$. При непрерывных $f_i$ и $\partial f_i/\partial x_j$ решение существует и единственно. Систему сводят к одному уравнению порядка $n$ исключением; уравнение $y^{(n)}=f$ сводят к системе введением $x_1=y,\ldots,x_n=y^{(n-1)}$.
