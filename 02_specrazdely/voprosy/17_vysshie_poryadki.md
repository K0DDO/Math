# Вопрос 17. Уравнения высших порядков. Задача Коши. Геометрический и механический смысл. Понижение порядка

## Что спрашивают на экзамене

ДУ порядка $n$. **Задача Коши** для высшего порядка. Теорема существования и единственности. **Геометрический** и **механический** смысл (особенно для 2-го порядка). Основные случаи **понижения порядка**.

## Все понятия с нуля

**ДУ порядка $n$:**

$$F\bigl(x,y,y',\ldots,y^{(n)}\bigr)=0,$$

или в разрешённом виде

$$y^{(n)}=f\bigl(x,y,y',\ldots,y^{(n-1)}\bigr).$$

([урок](https://mathprofi.ru/differencialnye_uravnenija_dopuskajushie_ponizhenie_poryadka.html))

**Задача Коши:** найти решение с начальными условиями в точке $x_0$:

$$y(x_0)=y_0,\quad y'(x_0)=y_0',\quad \ldots,\quad y^{(n-1)}(x_0)=y_0^{(n-1)}.$$

Нужно задать значение функции и все производные до порядка $n-1$ — всего $n$ условий (как $n$ постоянных в общем решении). ([урок](https://mathprofi.ru/differencialnye_uravnenija_primery_reshenii.html))

**Теорема существования и единственности.** Если $f$ и частные производные $\frac{\partial f}{\partial y},\ldots,\frac{\partial f}{\partial y^{(n-1)}}$ непрерывны в области, содержащей точку Коши $\,(x_0,y_0,\ldots,y_0^{(n-1)})$, то в окрестности $x_0$ существует единственное решение задачи Коши. ([урок](https://mathprofi.ru/differencialnye_uravnenija_primery_reshenii.html))

### Геометрический смысл (порядок 2)

Для $y''=f(x,y,y')$ начальные данные $y(x_0)=y_0$, $y'(x_0)=y_0'$ задают **точку** на плоскости и **наклон касательной**. Через «точку с направлением» проходит единственная интегральная кривая (при условиях теоремы). Кривизна / вторая производная определяется уравнением.

### Механический смысл

Пусть независимая переменная — время $t$, $y(t)$ — координата точки на прямой. Тогда:
- $y'$ — скорость,
- $y''$ — ускорение.

Уравнение $y''=f(t,y,y')$ — закон движения (аналог $ma=F$). Задача Коши: задать **начальное положение** и **начальную скорость** — дальше движение определено однозначно.

Пример: $y''=-y$ — гармонический осциллятор; $y(0)=0$, $y'(0)=1$ → $y=\sin t$.

## Теория подробно: понижение порядка

### Тип 1. Правая часть зависит только от $x$

$$y^{(n)}=f(x).$$

Интегрируем $n$ раз:

$$y^{(n-1)}=\int f\,dx+C_1,\quad \ldots,\quad y=\ldots+C_1\frac{x^{n-1}}{(n-1)!}+\ldots+C_n.$$

([урок](https://mathprofi.ru/differencialnye_uravnenija_dopuskajushie_ponizhenie_poryadka.html))

### Тип 2. Нет явной искомой функции $y$ (и младших производных)

Уравнение вида $F(x,y',y'',\ldots,y^{(n)})=0$ (нет $y$). Замена $z=y'$, тогда порядок падает на 1:

$$F(x,z,z',\ldots,z^{(n-1)})=0.$$

Частный случай 2-го порядка: $F(x,y',y'')=0$ → $z'=f(x,z)$. ([урок](https://mathprofi.ru/differencialnye_uravnenija_dopuskajushie_ponizhenie_poryadka.html))

### Тип 3. Нет явной независимой переменной $x$

$F(y,y',y'')=0$ (для 2-го порядка). Замена: $p=y'$, считаем $p=p(y)$, тогда

$$y''=\frac{dp}{dx}=\frac{dp}{dy}\cdot\frac{dy}{dx}=p\frac{dp}{dy}.$$

Получаем уравнение 1-го порядка относительно $p(y)$. ([урок](https://mathprofi.ru/differencialnye_uravnenija_dopuskajushie_ponizhenie_poryadka.html))

### Тип 4. Другие спецслучаи

Однородность по $y,y',\ldots$; уравнение Эйлера и т.д. — часто на более поздних вопросах. Главное на в.17 — первые три типа.

## Как решать / алгоритм

1. Определить порядок и выписать, от каких переменных зависит $F$.
2. Выбрать тип понижения (нет $y$ / нет $x$ / только $x$).
3. Сделать замену; решить уравнение меньшего порядка.
4. Вернуться к $y$ (ещё одно интегрирование, если $z=y'$).
5. Для Коши найти все постоянные из условий.
6. Интерпретировать: геометрия (точка + касательная) или механика (положение + скорость).

## Разобранный пример

**Только $x$.** $y''=x$.

$$y'=\frac{x^2}{2}+C_1,\qquad y=\frac{x^3}{6}+C_1 x+C_2.$$

**Нет $y$.** $y''=y'$. Положим $z=y'$, $z'=z$ → $z=C_1 e^{x}$ → $y=C_1 e^{x}+C_2$.

**Нет $x$.** $y''=2y y'$. Пусть $p=y'$, $y''=p\frac{dp}{dy}$:

$$p\frac{dp}{dy}=2y p.$$

При $p\neq 0$: $\frac{dp}{dy}=2y$ → $p=y^2+C_1$ → $y'=y^2+C_1$, далее разделяющиеся. Также $p=0$ → $y=\mathrm{const}$.

**Коши / механика.** $y''=-y$, $y(0)=0$, $y'(0)=1$ → $y=\sin x$.

## Практика

1. $y'''=6$ — общее решение.
2. $xy''+y'=0$ (нет $y$) — понизить и решить.
3. $y''=y'$ при условиях $y(0)=1$, $y'(0)=2$.
4. Объяснить механический смысл условий $y(0)=A$, $y'(0)=V$ для $y''=-y$.

## Что сказать устно за 1 минуту

Уравнение порядка $n$ содержит производную до $y^{(n)}$. Задача Коши задаёт $y,y',\ldots,y^{(n-1)}$ в точке $x_0$; при непрерывности $f$ и нужных частных производных решение единственно. Геометрически для 2-го порядка это точка и касательная; механически — положение и скорость. Порядок понижают: если нет $y$ — замена $z=y'$; если нет $x$ — $p=y'$, $y''=p\,dp/dy$; если правая часть только от $x$ — многократное интегрирование.
