## Что реально уметь решать

- матрица оператора в новом базисе: $A'=T^{-1}AT$
- собственные числа, собственные векторы, диагонализация
- критерий Сильвестра для $Q(x,y,z)$
- $y'+P(x)y=Q(x)$, Бернулли, полные дифференциалы
- $y''+py'+qy=f(x)$ методом неопределённых коэффициентов и вариации
- линейная однородная система $X'=AX$ при простых / кратных / комплексных корнях
