# Спецразделы — оглавление по вопросам экзамена 2026

Стиль конспектов (см. [`_STYLE.md`](_STYLE.md)): **интуиция** → понятия с нуля (интуиция → определение → как проверить → Mathprofi) → полная теория → **примеры из мира** → алгоритм → разобранный пример → практика → устный ответ. Пишем развёрнуто: и «на пальцах», и строго.

Сначала обязательно: [**00. Базовые понятия**](00_bazovye_ponyatiya.md) (ранг, определитель, базис, ФСР системы…).

**Для голосовых / зубрёжки словами:** [определения по билетам для голоса](opredeleniya_dlya_golosa.md) — один файл, секции по билетам, почти без стен формул.

**Допуск по линейным операторам:** [теория + разборы + практика с ответами](dopusk_linejnye_operatory.md).

Краткий свод одним файлом (если удобнее листать): [теория](specrazdeli_theory.md), [практика](specrazdeli_practice.md).
