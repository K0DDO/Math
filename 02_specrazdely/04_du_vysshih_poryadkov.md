# Уравнения высших порядков, Вронскиан

## Введение / определения с нуля

Уравнение порядка \(n\): \(y^{(n)}=f(x,y,y',\ldots,y^{(n-1)})\).

Задача Коши: задают \(y(x_0),y'(x_0),\ldots,y^{(n-1)}(x_0)\) — \(n\) условий. Геометрически для \(n=2\): кривая через точку с заданным наклоном. Механически: положение и скорость в момент \(t_0\).

Теорема Пикара: если \(f\) и её частные по \(y,y',\ldots\) непрерывны, решение единственно.

Понижение порядка из конспекта:

- нет \(y\): \(y'=p(x)\), \(y''=p'\), порядок падает;
- нет \(x\): \(y'=p(y)\), \(y''=p\frac{dp}{dy}\);
- однородность по \(y,y',\ldots\) — подстановка \(y=e^{\int u}\).

**Линейное** порядка \(n\):

$$
y^{(n)}+a_{n-1}(x)y^{(n-1)}+\cdots+a_0(x)y=f(x).
$$

Если \(f=0\) — **однородное** (ЛОДУ). Оператор \(L[y]=y^{(n)}+\cdots+a_0 y\) линеен: \(L[\alpha y+\beta z]=\alpha L[y]+\beta L[z]\). Следствие: линейная комбинация решений ЛОДУ — снова решение.

Система функций линейно независима на промежутке, если \(\sum c_i y_i\equiv 0\Rightarrow\) все \(c_i=0\).

**Вронскиан:**

$$
W(y_1,\ldots,y_n)=\det\begin{pmatrix}
y_1&\cdots&y_n\\
y_1'&\cdots&y_n'\\
\vdots&&\vdots\\
y_1^{(n-1)}&\cdots&y_n^{(n-1)}
\end{pmatrix}.
$$

Для решений ЛОДУ: либо \(W\equiv 0\), либо \(W\neq 0\) нигде (формула Лиувилля). \(W\neq 0\) в точке \(\Leftrightarrow\) система — **фундаментальная система решений (ФСР)**.

Общее решение ЛОДУ: \(y=c_1 y_1+\cdots+c_n y_n\), где \(\{y_i\}\) — ФСР.

Общее решение ЛНДУ: \(y=y_{\text{одн}}+y_{\text{частн}}\).

Переменные коэффициенты: на 1 курсе реально спрашивают Эйлера \(x^n y^{(n)}+\cdots=0\) (замена \(x=e^t\)) и вариацию постоянных. Общих рецептов нет.

## Как решать (пошагово)

Понижение:

1. Выпиши, каких переменных нет.
2. Сделай замену из шпаргалки.
3. Получишь уравнение 1 порядка — решай предыдущей темой.
4. Вернись к \(y\): если \(p=y'\), интегрируй.

Вронскиан: если просят проверить независимость двух решений \(y_1,y_2\), посчитай \(W=y_1 y_2'-y_2 y_1'\). Ненулевой в точке — ФСР для уравнения 2 порядка.

## Примеры с разбором

### Пример 1. Нет \(y\)

\(y''=2y'\). \(p=y'\), \(p'=2p\), \(p=Ce^{2x}\), \(y=\frac{C}{2}e^{2x}+D\).

### Пример 2. Нет \(x\)

\(yy''=(y')^2\). \(p(y)\), \(p p'=p^2/y\) при \(p\neq 0\). \(\frac{dp}{p}=\frac{dy}{y}\), \(p=Ky\), \(y=Ae^{Kx}\). Плюс \(y=\text{const}\).

### Пример 3. Вронскиан

\(y_1=e^x\), \(y_2=e^{2x}\). \(W=e^x\cdot 2e^{2x}-e^{2x}e^x=e^{3x}\neq 0\). ФСР для уравнения 2 порядка (конкретно для \(y''-3y'+2y=0\)).

## Типичные ошибки / вопросы на экзамен

- понижать порядок, когда \(y\) на самом деле есть;
- считать \(W=0\) в одной точке доказательством зависимости решений ЛОДУ (для решений ЛОДУ достаточно одной точки);
- писать общее решение ЛНДУ без частного решения.

Вопросы 17–21.
