# ЧАСТЬ I. ИНТЕГРАЛЫ — ПРАКТИКА

## 1. Первообразная и неопределённый интеграл — практика

**Пример 1.** $\int (3x^2 - 4\sin x + 5e^x)dx$
$$ = 3\int x^2dx -4\int\sin x dx +5\int e^xdx = 3\cdot\frac{x^3}{3} -4(-\cos x)+5e^x+C = x^3+4\cos x+5e^x+C$$
Проверка: $(x^3+4\cos x+5e^x+C)' = 3x^2-4\sin x+5e^x$.

**Пример 2.** $\int \frac{dx}{\sqrt[3]{x}} = \int x^{-1/3}dx = \frac{x^{2/3}}{2/3}+C = \frac32 \sqrt[3]{x^2}+C$.

**Пример 3.** Найти первообразную $F$ для $f(x)=2x$ проходящую через $(1,3)$: $F=x^2+C$, $1+C=3\Rightarrow C=2$, $F=x^2+2$.

## 2. Замена переменной. Подведение под знак дифференциала — практика

**Пример 1 (подведение).** $\int \sin(5x+2)dx = [d(5x+2)=5dx] = \frac15\int \sin(5x+2)d(5x+2)= -\frac15\cos(5x+2)+C$.

**Пример 2.** $\int \frac{dx}{3x-7}= \frac13\int\frac{d(3x-7)}{3x-7}= \frac13\ln|3x-7|+C$.

**Пример 3 (замена).** $\int x e^{x^2}dx$, $t=x^2$, $dt=2xdx$:
$$= \frac12\int e^t dt = \frac12 e^{x^2}+C.$$

**Пример 4.** $\int \frac{x dx}{\sqrt{x^2+1}}$, $t=x^2+1$, $dt=2xdx$ → $\frac12\int t^{-1/2}dt = \sqrt{t}+C=\sqrt{x^2+1}+C$.

## 3. Интегрирование по частям — практика

**Пример 1.** $\int x\sin x dx$, $u=x, dv=\sin x dx$:
$$= -x\cos x + \int \cos x dx = -x\cos x+\sin x+C.$$

**Пример 2.** $\int \ln x dx$, $u=\ln x, dv=dx$:
$$= x\ln x - \int x\cdot\frac{dx}{x}= x\ln x -x+C = x(\ln x-1)+C.$$

**Пример 3.** $\int x^2 e^x dx$ — дважды по частям:
$$= x^2 e^x -2\int x e^xdx = x^2 e^x-2(x e^x-\int e^xdx)= e^x(x^2-2x+2)+C.$$

**Пример 4 (циклический).** $\int e^x\sin x dx = [u=e^x] $ → дважды → $= \frac{e^x(\sin x-\cos x)}{2}+C$.

## 4. Дробно-рациональные функции — практика

**Пример 1.** $\int \frac{dx}{x^2-5x+6}= \int \frac{dx}{(x-2)(x-3)} = \int\left(\frac{-1}{x-2}+\frac1{x-3}\right)dx = -\ln|x-2|+\ln|x-3|+C = \ln\left|\frac{x-3}{x-2}\right|+C$.

**Пример 2.** $\int \frac{2x+3}{x^2+2x+5}dx$ — выделяем производную знаменателя $2x+2$:
$$= \int\frac{(2x+2)+1}{x^2+2x+5}dx = \ln(x^2+2x+5)+ \frac12\arctan\frac{x+1}{2}+C.$$

**Пример 3.** $\int \frac{dx}{x(x+1)^2}$ — разложение $A/x + B/(x+1)+ C/(x+1)^2$ → $A=1,B=-1,C=-1$ → $\ln|x|-\ln|x+1|+1/(x+1)+C$.

## 5. Тригонометрические выражения — практика

**Пример 1.** $\int \sin^3 x dx = \int \sin^2 x\sin x dx = \int (1-\cos^2x)\sin x dx$, $t=\cos x$ → $-\int(1-t^2)dt = -t+ t^3/3+C = -\cos x+\cos^3x/3+C$.

**Пример 2.** $\int \cos^2 x dx = \int \frac{1+\cos2x}{2}dx = \frac{x}{2}+\frac{\sin2x}{4}+C$.

**Пример 3 (универсальная).** $\int \frac{dx}{1+\sin x}$, $t=\tan x/2$ → $= \int \frac{2dt/(1+t^2)}{1+2t/(1+t^2)} = \frac{2}{t+1}+C = \frac{2}{\tan x/2+1}+C = -\frac{2\cos x}{\sin x+\cos x+1}$ — после упрощений также $= -\frac{2}{\tan(x/2)+1}$; часто дают ответ $-2/(1+\tan x/2)$.

**Пример 4.** $\int \sin x\cos x dx = \frac12\int \sin2x dx = -\frac14\cos2x+C = \frac12\sin^2x+C$.

## 6. Иррациональные выражения — практика

**Пример 1.** $\int \frac{dx}{\sqrt{x}+\sqrt[3]{x}}$, НОК 2 и 3 =6, $x=t^6$, $dx=6t^5dt$:
$$= \int \frac{6t^5dt}{t^3+t^2}=6\int\frac{t^3}{t+1}dt =6\int(t^2-t+1-1/(t+1))dt =2t^3-3t^2+6t-6\ln|t+1|+C,\ t=\sqrt[6]{x}.$$

**Пример 2.** $\int \sqrt{4-x^2}dx$, $x=2\sin t$ → $=2\arcsin(x/2)+x\sqrt{4-x^2}/2+C$.

**Пример 3.** $\int \frac{dx}{\sqrt{x^2+2x+5}}$, выделяем $(x+1)^2+4$, $t=x+1$, $= \ln|t+\sqrt{t^2+4}|+C$.

## 7. Определённый интеграл. Интегральная сумма — практика

**Пример 1.** $\int_0^2 x^2dx = x^3/3|_0^2=8/3$. Геометрически — площадь под параболой. Интегральная сумма Римана $\sigma=\sum \xi_i^2\Delta x_i \to 8/3$.

**Пример 2.** $\int_1^3 (2x+1)dx = (x^2+x)|_1^3 =12-2=10$.

**Пример 3.** Проверка существования: $\int_{-1}^{1}\frac{dx}{x}$ — не существует (разрыв в 0, 2 рода), а $\int_0^1 \sqrt{x}dx$ существует т.к. непрерывна.

## 8. Свойства определённого интеграла — практика

**Пример 1.** Оценить $\int_0^1 e^{x^2}dx$: $1\le e^{x^2}\le e$ → $1\le I\le e$.

**Пример 2.** $\int_{-2}^{2} x^3dx =0$ т.к. нечётная на симметричном.

**Пример 3.** Теорема о среднем: $\int_0^{\pi} \sin x dx =2 = \pi\cdot\sin c$ → $c=\arcsin(2/\pi)$.

**Пример 4.** Аддитивность: $\int_0^2 |x-1|dx = \int_0^1 (1-x)dx+\int_1^2 (x-1)dx =1$.

## 9. Интеграл с переменным пределом. Ньютон-Лейбниц — практика

**Пример 1.** $F(x)=\int_0^x t^2dt = x^3/3$, $F'(x)=x^2$.

**Пример 2.** $\int_1^e \frac{dx}{x}=\ln x|_1^e=1$.

**Пример 3.** $\int_0^{\pi/2}\cos x dx = \sin x|_0^{\pi/2}=1$.

**Пример 4.** $(\int_{2}^{x}\frac{dt}{1+t^2})' = 1/(1+x^2)$ (Барроу).

## 10. Замена и по частям в определённом — практика

**Замена.** $\int_0^1 x e^{x^2}dx$, $t=x^2$, пределы $0→0$, $1→1$ → $\frac12\int_0^1 e^t dt = (e-1)/2$.

**Замена поляр.** $\int_0^{\sqrt3}\frac{xdx}{\sqrt{1+x^2}}$, $t=1+x^2$ → $= \sqrt{4}-\sqrt1=1$.

**По частям.** $\int_0^1 x e^xdx = x e^x|_0^1-\int_0^1 e^xdx =1$.

**По частям.** $\int_1^e \ln x dx = x\ln x|_1^e-\int_1^e dx =1$.

## 11. Площади в декартовой и полярной — практика

**Декарт.** $y=x^2$, $y=2x$ пересекаются $x=0,2$: $S=\int_0^2 (2x-x^2)dx = [x^2 - x^3/3]_0^2=4/3$.

**Декарт между кривыми.** $y=\sqrt{x}$, $y=x^2$ → $S=\int_0^1 (\sqrt{x}-x^2)dx=1/3$.

**Полярная.** Кардиоида $\rho=1+\cos\varphi$: $S=\frac12\int_0^{2\pi}(1+\cos\varphi)^2d\varphi = \frac32\pi$.

**Полярная роза** $\rho=2\sin2\varphi$ (4 лепестка) один лепесток $0→\pi/2$: $S_1=\frac12\int_0^{\pi/2}4\sin^22\varphi d\varphi=\pi/2$, вся $2\pi$.

## 12. Параметрическая площадь + поверхность вращения — практика

**Эллипс** $x=2\cos t$, $y=\sin t$: $S=|\int_0^{2\pi} y x' dt|=|\int_0^{2\pi} \sin t(-2\sin t)dt|=2\pi$.

**Циклоида** $x=t-\sin t$, $y=1-\cos t$, $0→2\pi$: $S=\int_0^{2\pi} y x' dt =3\pi$ (арка).

**Поверхность.** $y=\sqrt{x}$, $0→1$ вокруг $Ox$: $P=2\pi\int_0^1 \sqrt{x}\sqrt{1+1/(4x)}dx = \frac{\pi}{6}(5\sqrt5-1)$.

## 13. Объёмы по сечениям и вращения в декартовой — практика

**Шар** $y=\sqrt{R^2-x^2}$: $V=\pi\int_{-R}^{R}(R^2-x^2)dx=\frac43\pi R^3$.

**Конус** $y= (r/h)x$, $0→h$ вокруг $Ox$? вокруг $Ox$ параболоид; для конуса вокруг $Ox$ берут $y= (R/h)x$: $V=\pi\int_0^h (R x/h)^2dx=\pi R^2 h/3$.

**Между кривыми.** $y=x^2$, $y=\sqrt{x}$ вокруг $Ox$: $V=\pi\int_0^1 (x - x^4)dx=\frac{3\pi}{10}$.

**По сечениям.** Пирамида сечением $S(x)= (a x/h)^2$ → $V=\int_0^h a^2 x^2/h^2 dx = a^2 h/3$.

## 14. Объёмы в полярных и параметрических — практика

**Параметрически.** Эллипс $x=3\cos t$, $y=2\sin t$ вращаем вокруг $Ox$: $V=\pi\int y^2|x'|dt = \pi\int_0^{\pi}4\sin^2t\cdot3\sin t dt? — правильнее $V=\pi\int_{\alpha}^{\beta} y^2 x' dt$ с модулем: $V=16\pi$ (эллипсоид $4\pi a b^2/3=16\pi$).

**Полярная.** Полукруг $\rho=2R\cos\varphi$, $-\pi/2→\pi/2$ вращаем вокруг полярной оси → шар.

## 15. Длина дуги в декарте — практика

**Пример 1.** $y= \frac23 (x^2+1)^{3/2}$, $0→1$: $y'=2x\sqrt{x^2+1}?$ — на сайте берут $y=\ln x$ и т.д. Простой: $y=x^2/2$, $y'=x$, $L=\int_0^1\sqrt{1+x^2}dx = [\frac12(x\sqrt{1+x^2}+\operatorname{arsinh}x)]_0^1$.

**Пример 2.** Полукубическая парабола $y=\frac23 x^{3/2}$, $0→3$: $L=\int_0^3\sqrt{1+x}dx = \frac23[(1+x)^{3/2}]_0^3=14/3$.

**Пример 3.** $y=\operatorname{ch}x$, $0→1$: $L=\int_0^1\sqrt{1+\sinh^2x}dx=\int_0^1\cosh x dx=\sinh1$.

## 16. Длина в полярных и параметрических — практика

**Параметрическая окружность** $x=\cos t$, $y=\sin t$: $L=\int_0^{2\pi}1 dt=2\pi$.

**Астроида** $x=a\cos^3t$, $y=a\sin^3t$: $L=\int_0^{2\pi}3a|\sin t\cos t|dt =6a$.

**Полярная кардиоида** $\rho=a(1+\cos\varphi)$: $L=\int_0^{2\pi}\sqrt{a^2(1+\cos)^2+a^2\sin^2}d\varphi=8a$.

## 17. Несобственные 1 рода — практика (признаки сравнения)

**Пример 1.** $\int_1^{\infty}\frac{dx}{x^2+1}$ — сходится? Сравним с $1/x^2$: предел $1$ → сходится, $=\pi/2-\pi/4=\pi/4$.

**Пример 2 (расходится).** $\int_1^{\infty}\frac{dx}{\sqrt{x}} = \lim 2\sqrt{b}-2 =\infty$.

**Пример 3 (эталон).** $\int_1^{\infty}\frac{x+1}{x^3+2}dx \sim 1/x^2$ → сходится.

**Пример 4.** $\int_0^{\infty} e^{-x}dx =1$ — сходится.

## 18. Коши, Дирихле — практика

**Пример Дирихле.** $\int_1^{\infty}\frac{\sin x}{x}dx$ — $f=\sin x$ первообразная ограничена $|\int_1^A\sin|=|\cos1-\cos A|\le2$, $g=1/x\downarrow0$ → сходится условно.

**Пример расходимости.** $\int_1^{\infty}\frac{\sin x}{\sqrt{x}}dx$ тоже сходится по Дирихле, а $\int_1^{\infty}|\sin x|/\sqrt{x}$ расходится.

**Критерий Коши на практике** — оценка хвоста: для $\int_1^{\infty}dx/x^2$, хвост $<\varepsilon$ при $b'>1/\varepsilon$.

## 19. Абсолютная сходимость + главное значение + эталон 1 рода — практика

**Абсолютная.** $\int_1^{\infty}\frac{\sin x}{x^2}dx$ — $|\cdot|\le1/x^2$ → абсолютно сходится.

**Условная.** $\int_1^{\infty}\frac{\sin x}{x}dx$ — условно, как выше.

**Главное значение.** $V.p.\int_{-\infty}^{\infty}\frac{xdx}{1+x^2}=0$ (нечётная), но обычный расходится (два предела независимы: $\int_0^R \to \infty$).

**Эталон.** $\int_1^{\infty}\frac{dx}{x^p}$ — тест: $p=1.5$ сходится, $p=0.8$ расходится.

## 20. Несобственные 2 рода — практика

**Пример 1.** $\int_0^1\frac{dx}{\sqrt{x}} = \lim_{\varepsilon→0}2\sqrt{x}|_{\varepsilon}^1=2$ — сходится ($q=1/2<1$).

**Пример 2.** $\int_0^1\frac{dx}{x}$ — $\ln x|_{\varepsilon}^1→\infty$ — расходится ($q=1$).

**Пример 3.** $\int_0^1\frac{dx}{\sqrt{1-x^2}} = \arcsin x|_0^1 =\pi/2$ — сходится (разрыв в 1).

**Сравнение.** $\int_0^1\frac{e^x}{\sqrt[3]{x}}dx \sim 1/x^{1/3}$ → сходится.

## 21. Эталон 2 рода + связь 1-2 — практика

**Эталон.** $\int_0^1\frac{dx}{(1-x)^{0.7}}$ сходится; $\int_0^1\frac{dx}{(1-x)^{1.2}}$ расходится.

**Связь.** Замена $x=1/t$: $\int_1^{\infty}\frac{dx}{x^2}=\int_0^1 dt =1$ — показывает, что $p>1$ соответствует $q<1$.

**Смешанный.** $\int_0^{\infty}\frac{dx}{\sqrt{x}(1+x)}$ — разбивают $0→1$ (2 рода $q=1/2$) + $1→∞$ (1 рода $p=3/2$) — оба сходятся → весь сходится $=\pi$.

## 22. Главные значения 1 и 2 рода — практика

**1 рода.** $\int_{-1}^{1}\frac{dx}{x}$ обычный расходится ($\ln$), $V.p.=\lim_{\varepsilon}(\int_{-1}^{-\varepsilon}+\int_{\varepsilon}^{1}) =0$.

**1 рода симметрия.** $V.p.\int_{-\infty}^{\infty}x^3dx=0$, обычный расходится.

**2 рода.** $\int_{-1}^{1}\frac{dx}{x^2}$ — $V.p.=\infty$ (чётная, не компенсируется).

**Проверка.** $\int_0^2\frac{dx}{(x-1)^2}$ — $V.p.=\infty$, обычный расходится (два бесконечных плюса).

# ЧАСТЬ II. РЯДЫ — ПРАКТИКА

## 1. Ряд, частичная сумма, необходимое условие — практика

**Пример 1.** $\sum_{n=1}^{\infty}\frac1{n(n+1)}$ — $S_n=1-1/(n+1)→1$ → сходится, сумма 1.

**Пример 2.** $\sum \frac{n}{n+1}$ — $a_n→1\neq0$ → расходится (необходимое нарушено).

**Пример 3.** $\sum (-1)^n$ — $a_n\not→0$ → расходится.

**Свойства:** отбрасывание 10 первых членов не меняет сходимости, но меняет сумму.

## 2. Гармонический — практика

**Пример.** $S_{2n}>1+n/2$ — расходится. Частичные $S_1=1$, $S_2=1.5$, $S_4≈2.08$ — растёт логарифмически.

**Контрпример.** $1/n→0$ но ряд расходится — необходимое не достаточно.

## 3. Геометрический — практика

**Пример 1.** $\sum_{n=0}^{\infty}(1/2)^n = 1/(1-1/2)=2$.

**Пример 2.** $\sum_{n=1}^{\infty}3(2/3)^{n-1}= 3/(1-2/3)=9$.

**Пример 3.** $\sum (-1)^n$ — $|q|=1$ расходится; $\sum 2^n$ — $|q|=2$ расходится.

**Сумма как пример:** $0.333... = \sum 3/10^n = 1/3$.

## 4. Признаки сравнения — практика

**Пример 1.** $\sum \frac{n+1}{n^3+2} \sim 1/n^2$ → $\lim a_n/(1/n^2)=1$ → сходится (эталон $p=2>1$).

**Пример 2.** $\sum \frac{1}{\sqrt{n^2+1}} \sim 1/n$ → расходится.

**Пример 3.** $\sum \frac{\ln n}{n^2} \le C/n^{1.5}$ при больших $n$ → сходится (мажоранта).

## 5. Даламбер и Коши — практика

**Даламбер.** $\sum n!/3^n$: $D=\lim (n+1)/3 =\infty>1$ → расходится.

**Даламбер.** $\sum 3^n/n!$ : $D=0$ → сходится.

**Коши.** $\sum (n/(2n+1))^n$: $C=\lim n/(2n+1)=1/2<1$ → сходится.

**Коши.** $\sum (1+1/n)^{n^2}$: $\sqrt[n]{a_n}=(1+1/n)^n→e>1$ → расходится.

**Случай $D=1$.** $\sum 1/n$, $\sum 1/n^2$ оба дают 1 — нужен другой признак.

## 6. Интегральный признак — практика

**Пример 1.** $\sum 1/(n\ln n)$ при $n≥2$: $\int_2^{\infty}dx/(x\ln x)=\ln\ln x|_2^{\infty}=\infty$ → расходится.

**Пример 2.** $\sum 1/n^2$: $\int_1^{\infty}dx/x^2=1$ → сходится, остаток $R_n\le 1/n$.

## 7. Обобщённый гармонический — практика

**Пример 1.** $\sum 1/\sqrt{n}$ ($p=0.5$) расходится.

**Пример 2.** $\sum 1/n^{1.1}$ сходится.

**Пример 3.** $\sum 1/(n\sqrt[3]{n}) = \sum 1/n^{4/3}$ сходится.

**Сравнение:** $\sum (n^2+1)/(n^4+2) \sim 1/n^2$ → сходится.

## 8. Лейбниц — практика

**Пример 1.** $\sum (-1)^{n+1}/n$ → $b_n=1/n\downarrow0$ → сходится условно, $S≈\ln2$, $|R_n|\le1/(n+1)$. Для $\varepsilon=0.01$ нужно $n=100$.

**Пример 2.** $\sum (-1)^n/\sqrt{n}$ → сходится, остаток ≤ $1/\sqrt{n+1}$.

**Немонотонность:** $\sum (-1)^n (1/n+(-1)^n/n^2)$ — проверить монотонность $b_n$, может нарушаться.

## 9. Абсолютная/условная — практика

**Пример 1.** $\sum (-1)^n/n^2$ — $|a_n|=1/n^2$ сходится → абсолютно.

**Пример 2.** $\sum (-1)^n/n$ — $|a_n|$ гармонический расходится, сам по Лейбницу сходится → условно.

**Пример 3.** $\sum \sin n / n^2$ — $|\sin n|/n^2 ≤1/n^2$ → абсолютно.

**Перестановка:** условно сходящийся $\sum (-1)^{n+1}/n$ перестановкой можно получить $1.5\ln2$, абсолютно — нет.

## 10. Функциональные ряды, область сходимости — практика

**Пример 1.** $\sum x^n$ — по Коши $|x|<1$ → $(-1,1)$, на концах $x=±1$ расходится.

**Пример 2.** $\sum x^n/n$ — $R=1$, интервал $(-1,1)$, $x=1$ гарм. расходится, $x=-1$ Лейбниц сходится → $[-1,1)$.

**Пример 3.** $\sum (x-2)^n/n$ — центр 2 → $(1,3)$.

## 11. Равномерная сходимость — практика

**Пример равномерной.** $\sum \sin nx / n^2$ на $\mathbb R$: мажоранта $1/n^2$ → равномерно.

**Пример неравномерной.** $\sum x^n$ на $(-1,1)$ поточечно к $1/(1-x)$, но неравномерно (всплеск у $x→1$). На $[-0.5,0.5]$ равномерно ($|x|^n ≤0.5^n$).

**Геометрический тест:** строим коридор $±\varepsilon$ вокруг $S(x)$, проверяем весь отрезок.

## 12. Признак Вейерштрасса — практика

**Пример 1.** $\sum e^{-n} \cos nx$ на $\mathbb R$: $|\cdot|≤ e^{-n}$, $\sum e^{-n}$ сходится → равномерно.

**Пример 2.** $\sum x^n/n!$ на $[-10,10]$: $|x|^n/n! ≤10^n/n!$ → равномерно (мажоранта сходится).

**Не подходит:** $\sum x^n$ на $(-1,1)$ нельзя мажорировать $1$.

## 13. Непрерывность суммы — практика

**Пример.** $\sum x^n$ на $[0,0.9]$ равномерно → сумма $1/(1-x)$ непрерывна (ок).

**Контрпример.** $S_n= x^n$ на $[0,1]$: $S_n→0$ при $x<1$, $1$ при $x=1$ — предел разрывен, сходимость неравномерна.

## 14. Почленное интегрирование/дифференцирование — практика

**Интегрирование.** $\sum x^n =1/(1-x)$ на $[0,0.5]$ равномерно → $\int_0^{0.5}\sum x^n dx = \sum \int_0^{0.5}x^n dx = \sum 0.5^{n+1}/(n+1)= -\ln0.5$.

**Дифференцирование.** $\sum x^n/n = -\ln(1-x)$: дифференцируем → $\sum x^{n-1}=1/(1-x)$ верно внутри $(-1,1)$.

**Проверка условий:** дифференцировать $\sum \sin n^2 x / n^2$ почленно нельзя — производный ряд $\sum \cos n^2 x$ расходится.

## 15. Степенной ряд, Абель, радиус — практика

**Пример 1.** $\sum n x^n$: $R=\lim |c_n/c_{n+1}|=1$.

**Пример 2.** $\sum x^n/n!$ : $R=\infty$ → вся прямая.

**Пример 3.** $\sum n! x^n$ : $R=0$ → только $0$.

**Абель:** если сходится в $x=2$, то абсолютно в $(-2,2)$.

## 16. Равномерная степенного — практика

**Пример.** $\sum x^n$ на $[-0.8,0.8]$ равномерно, на $(-1,1)$ нет.

**Следствие:** внутри $(-1,1)$ можно интегрировать: $\int_0^x \sum t^n dt = \sum x^{n+1}/(n+1)$.

## 17. Единственность, Тейлор, Маклорен — практика

**Пример.** Разложение $e^x$ единственно: если нашли $1+x+x^2/2+...$ любым способом — это Тейлор.

**Маклорен.** $\sin x$ — нечётная → только нечётные степени.

## 18. Достаточное условие + стандартные — практика

**Стандартные (проверка остатка):**
- $e^{0.5}=1+0.5+0.125+0.0208+...≈1.648$,
- $\sin0.2≈0.2-0.2^3/6=0.1987$ (точно 0.198669),
- $\ln1.1 =0.1-0.005+...≈0.0953$,
- $(1+0.1)^{1/2}=1+0.05-0.00125...≈1.0488$.

**Остаток Лагранжа** для $e^x$ на $[-1,1]$: $|R_n|≤ e/(n+1)!$.

## 19. Приближённые вычисления — практика

**Пример 1.** $\sqrt[3]{30}=3\sqrt[3]{1+0.037}=3(1+0.037/3-0.037^2/9...)=3.107...$.

**Пример 2.** $\int_0^{0.5} e^{-x^2}dx = \int_0^{0.5}(1-x^2+x^4/2-...)dx =0.5-0.0417+0.0031...≈0.461$.

**Пример 3.** $\int_0^1 \sin x /x dx = \int_0^1(1-x^2/6+...)dx=0.946$.

## 20. ДУ через ряды — практика

**Пример.** $y'=y$, $y(0)=1$ → $y=\sum x^n/n! = e^x$.

**Пример.** $y'=x+y$, $y(0)=0$: $y''=1+y'$, $y'(0)=0$, $y''(0)=1$, $y'''=y''$, → $y= x^2/2!+x^3/3!+...=e^x -x-1$.

**Численно:** $y'=x^2+y^2$, $y(0)=0$ → $y= x^3/3 + x^7/63+...$.

## 21. ОНС, тригонометрическая система — практика

**Пример.** Проверить ортогональность: $\int_{-\pi}^{\pi}\cos nx\sin mx dx=0$, $\int_{-\pi}^{\pi}\cos nx\cos mx dx=0$ ($n≠m$), $=\pi$ ($n=m$).

**Коэффициенты Фурье** для $f(x)=x$: $c_n=(f,\varphi_n)$ → $a_n=0$, $b_n=2(-1)^{n+1}/n$.

## 22. Ряд Фурье, Дирихле — практика

**Пример.** $f(x)=x$ на $(-\pi,\pi)$, $f(-\pi)=f(\pi)$? разрыв при периодизации: ряд в $x=\pi$ сходится к $0$ (среднее $-\pi$ и $\pi$).

**Вычисление:** $f(x)= |x|$ — чётная, коэффициенты $a_0=\pi$, $a_n=2((-1)^n-1)/(\pi n^2)$.

## 23. Спектр — практика

**Пример.** $f(x)=\sin x + 0.5\sin2x$ — спектр $A_1=1$, $A_2=0.5$, остальные 0.

**Пример пилы** $f(x)=x$ → $A_n=2/n$ → убывает как $1/n$ (разрыв → медленно).

## 24. Чётные/нечётные — практика

**Чётная.** $f(x)=x^2$ на $(-\pi,\pi)$: только косинусы $a_n=4(-1)^n/n^2$, $b_n=0$ → $x^2=\pi^2/3+4\sum (-1)^n\cos nx/n^2$.

**Нечётная.** $f(x)=x$ → только синусы как выше.

**Продолжение.** $f(x)=1$ на $(0,\pi)$ чётно → $1$ (только $a_0$), нечётно → $\frac4\pi\sum \sin(2k-1)x/(2k-1)$.
