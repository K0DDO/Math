# Спецразделы математики — подготовка к экзамену

Только спецразделы (линейные операторы, квадратичные формы, дифференциальные уравнения и системы). Матанализ убран.

Формат как в [K0DDO/Algo](https://github.com/K0DDO/Algo): **один вопрос — один файл**. Стиль: интуиция + понятия с нуля + полная теория + примеры из мира + алгоритм + разобранный пример + практика + устный ответ (см. [`02_specrazdely/_STYLE.md`](02_specrazdely/_STYLE.md)).

Источник теории и разборов: [лекции Mathprofi](https://mathprofi.ru/lekcii_po_vysshei_matematike.html).

## С чего начать

1. Прочитай [базовые понятия с нуля](02_specrazdely/00_bazovye_ponyatiya.md) — вектор, матрица, определитель, **ранг**, ядро системы, базис и т.д.
2. Иди по вопросам из файла преподавателя по порядку: [оглавление](02_specrazdely/README.md).
3. На каждый вопрос: закрой ответ → реши практику сам → сверься.
4. Устно проговори блок «Что сказать устно за 1–2 минуты».

Блоки ДУ высших порядков и систем (вопросы 21–30) переписаны развёрнуто: переменные коэффициенты и Эйлер, вариация, постоянные коэффициенты, спецправая часть, нормальные системы и спектр $A$, неоднородные системы.

Исходник вопросов: [`02_specrazdely/istochniki/Вопросы_к_экзамену_по_спецразделам_2026.docx`](02_specrazdely/istochniki/Вопросы_к_экзамену_по_спецразделам_2026.docx).
