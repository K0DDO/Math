# Математика, 1 курс, 2 семестр

Конспект в том же духе, что [K0DDO/Algo](https://github.com/K0DDO/Algo): одна тема — один файл, сначала определения с нуля, потом алгоритм решения, потом разобранные примеры, потом экзаменационные вопросы и практика со ссылками на решебники.

Сложность практики подогнана под `Тест на 60 баллов 2 семестр 2024`: посчитать интеграл, исследовать сходимость, найти площадь/объём, дать определение, определить тип поля. Это обычный втузовский уровень, не олимпиада.

## Как пользоваться

1. Открой тему, прочитай определения и «как решать».
2. Разбери пример руками, не глядя в ответ.
3. По ссылкам из блока **Практика** пройди урок на Mathprofi — там учат решать, а не только формулируют теоремы.
4. Пореши задачи из Кузнецова / Демидовича / Филиппова. Номера даны. Решения — по ссылкам на решебники.
5. Проверь себя по списку экзаменационных вопросов в конце темы и в `voprosy_ekzamen.md`.

Не копируй готовые решения. Схема: закрыл решебник → решил → открыл и сверился.

## Две папки — два экзамена

| Папка | Что сдаёшь | Откуда взято |
|---|---|---|
| [`01_matanliz/`](01_matanliz/README.md) | интегралы, ряды, кратные интегралы, поля | опорные конспекты + вопросы по интегралам/рядам + тест на 60 |
| [`02_specrazdely/`](02_specrazdely/README.md) | линейные операторы, квадратичные формы, диффуры | опорный конспект по ДУ + вопросы по спецразделам 2026 |

Тест на 60 баллов — это **матанализ** 2 семестра (определённый/несобственный интеграл, площадь, полный дифференциал, двойной/тройной, криволинейный, поверхностный, векторное поле). В вопросы по спецразделам он не входит: там операторы и дифференциальные уравнения.

## Главные решебники

Их хватит на весь курс. Конкретные уроки и номера задач — внутри каждой темы.

- [Mathprofi](https://mathprofi.ru/) — лучший самоучитель «научиться решать». Минимум теории, максимум разборов.
- [Math24](https://math24.ru/) — те же темы, другой стиль, удобно как второй источник.
- [Кузнецов, типовые расчёты, решебник](http://mat-an.ru/kuznecov.php) — уровень почти один в один с тестом на 60.
- [Кузнецов на reshebnik.ru](https://reshebnik.ru/tasks/)
- [Филиппов, диффуры, решебник](https://taskall.ru/Filippov/index.htm)
- [Филиппов, список решённых номеров](http://mat-an.ru/filippov.php)
- [WolframAlpha](https://www.wolframalpha.com/) — проверить ответ после того, как решил сам.
